What is JSX?

JSX is a syntax extension for JavaScript used in React 
that allows us to write HTML-like code inside JavaScript.

example:

import React from "React"

const name = "John";

return (
  < h1 >Hello {name}< /h1>
);

You cant do this directly in normal HTML
< h1>Hello {name}< /h1>

What is Virtual DOM?

Virtual DOM is a lightweight representation of the real DOM 
maintained by React. When state or props change, 
React compares the new Virtual DOM with 
the previous one and updates only the necessary parts of 
the real DOM, which helps make UI updates more efficient.

Virtual DOM = a copy/representation of the UI

Reconciliation = the process of comparing the old and new Virtual DOM
to determine what has changed and then updates the necessary parts of the real DOM.

function FetchApi() {

      {error && < p> Error {error}}

        product.map((item, index) => (
          < ul key={index}>
            < li>
              < img alt="image" 
               style={{ width: "200px" }} 
               src={item.image} />
              < p>{item.title}< / p>
            < / li>
          
        ))}
     
      < h1 >FetchData< /h1>
    < /div>
  );
}

export default FetchApi;

Conditional Rendering in React?

Conditional rendering means showing different UI based on a condition.

It's basically using if, else, or 
a ternary operator to decide what should appear on the screen.

example:

function App() {
  const isLoggedIn = true;

  return (
    < div>
      {isLoggedIn ? < h1>Welcome!< /h1> : < h1>Please Login< /h1>}
    < /div>
  );
}

Code Splitting in React?

Code splitting means dividing a big 
React application into smaller parts 
and loading them only when needed.

In React, we can use lazy() and Suspense for code splitting.

in src/components
Home
About
Products
Admin

Without code splitting, all pages are loaded at once:

Open website
     ↓
Load Home + About + Products + Admin

Open website
     ↓
Load Home
     ↓
User clicks Products
     ↓
Load Products


In React, we can use lazy():

import { lazy, Suspense } from "react";

const About = lazy(() => import("./About"));

function App() {
  return (
    < Suspense fallback={< p >Loading...< /p>}>
      < About />
    < /Suspense>
  );
}

export default App;

Here, About is loaded only when React needs it.

Closures?


A closure is a function that remembers the variables from its outer scope, 
even after that outer function has finished executing.

    Example:
    function outer() {
    let count = 0;

    function inner() {
        count++;
        console.log("Count is:", count);
    }

    return inner;
    }

    const counter = outer();  // outer() runs and returns inner()
    counter(); // Count is: 1
    counter(); // Count is: 2
    counter(); // Count is: 3
    // closure — a function holding on to a 
    local variable after the outer function has finished.

js scopes

i. Local Variable
A local variable is declared inside a function and can only be used inside that function.

    Example:

    function greet() {
    let name = "Rahul";
    console.log(name);
    }

    greet(); // Rahul

    console.log(name); // Error

    Here, name is local to the greet() function.


ii. Global Variable
A global variable is declared outside a function and 
can be accessed from different parts of the program.

    Example:

    let name = "Rahul";

    function greet() {
    console.log(name);
    }

    greet(); // Rahul
    console.log(name); // Rahul

What is hoisting in JavaScript?

Hoisting in Js is behavior of processing declarations before executing the code. 

    greet(); // output hello

    function greet() {
    console.log("Hello");
    }

    Function declarations are fully hoisted, 
    ----------------------------------------------------------------------------
    example with var

    var name;

    console.log(name); // undefined

    var variables are hoisted with an initial value of undefined; 
    ----------------------------------------------------------------------------

    name = "Rahul";

    console.log(name); // This gives a ReferenceError

    let name = "Rahul";

    let and const are hoisted but remain in the 
    Temporal Dead Zone (TDZ) until their declaration is reached.

Destructuring in JavaScript

Destructuring is a JavaScript feature that allows us to extract values from 
arrays or properties from objects and assign them to variables in a concise way.

    example

    const user = {
    name: "Rahul",
    age: 25,
    city: "Mumbai"
    };

    const { name, age, city } = user;

    console.log(name); // Rahul
    console.log(age);  // 25
    console.log(city); // Mumbai

    Instead of:

    const name = user.name;
    const age = user.age;
    const city = user.city;

    Rename variables:

    const user = {
    name: "Rahul",
    age: 25
    };

    const { name: userName, age: userAge } = user;

    console.log(userName); // Rahul
    console.log(userAge);  // 25

Higher-order functions?

Functions that takes other functions as arguments

example:

const numbers = [1, 2, 3, 4];

const doubled = numbers.map(x => x * 2);

console.log(doubled); // [2, 4, 6, 8]

Here, map is a higher-order function because 
it accepts another function (x => x * 2) as an argument.
