What is JS?

JS is a single-threaded, non-blocking asynchronous concurrent language. 
It is used as a client-side scripting language 
as well as server-side using Node.js.

var let const difference?

var is function-scoped & can be redeclared.
let is block-scoped & can be reassigned.
const is block-scoped cannot be reassigned after initalization.

Diff between null undefined?

null means you intentionally set the value to "nothing".

example:

let selectedUser = null;

console.log(selectedUser); // null
----------------------------------------------------------------------------

undefined usually means a variable exists, but no value has been assigned.

example:

const user = {};

console.log(user.age); // undefined

Event Loop in JS?.

As JS is single-threaded, 
the event loop manages async tasks by queuing them after synchronous tasks are done.

Example:
console.log("1. Start");

setTimeout(() => {
  console.log("2. Inside setTimeout");
}, 0);

console.log("3. End");

Output will be:
1. Start
3. End
2. Inside setTimeout

Explanation:
console.log("1. Start") runs first — it's synchronous.
setTimeout is asynchronous, so it's scheduled to run later.
console.log("3. End") runs next.

Callback Function?

A callback is a function passed as an argument to another function.
This technique allows a function to call another function.
A callback function can run after another function has finished.


Example:
function sayHi() {
  console.log("Hi");
}

function greet(callback) {
  callback();  // calling the passed-in function
}

greet(sayHi);

Output:
Hi

sayHi is passed as a callback to greet.
greet runs and calls sayHi using callback().
sayHi then prints "Hi" to the console.

Promise in JS?

A Promise is an object that represents the eventual completion (or failure) 
of an asynchronous operation and its resulting value.

const myPromise = new Promise((resolve, reject) => {
  const success = true; // Try changing this to false

  if (success) {
    resolve("✅ Promise resolved!");
  } else {
    reject("❌ Promise rejected!");
  }
});

myPromise
  .then((message) => {
    console.log("Then:", message);
  })
  .catch((error) => {
    console.log("Catch:", error);
  });

  Or

If you don’t want to use .then, use async await:
async function run() {
  try {
    const message = await myPromise;
    console.log("Then:", message);
  } catch (error) {
    console.log("Catch:", error);
  }
}

run();

Explanation:
new Promise((resolve, reject) => {...}) creates a new promise.
Inside the promise, based on success, it calls resolve() or reject().
.then() handles the success result.
.catch() handles any errors or rejection.

   Event Bubbling: Events move from child to parent.

Closures?


A closure is a function that remembers the variables from its outer scope, 
even after that outer function has finished executing.

    Example:
    function outer() {
    let count = 0;

    function inner() {
        count++;
        console.log("Count is:", count);
    }

    return inner;
    }

    const counter = outer();  // outer() runs and returns inner()
    counter(); // Count is: 1
    counter(); // Count is: 2
    counter(); // Count is: 3
    // closure — a function holding on to a 
    local variable after the outer function has finished.

js scopes

i. Local Variable
A local variable is declared inside a function and can only be used inside that function.

    Example:

    function greet() {
    let name = "Rahul";
    console.log(name);
    }

    greet(); // Rahul

    console.log(name); // Error

    Here, name is local to the greet() function.


ii. Global Variable
A global variable is declared outside a function and 
can be accessed from different parts of the program.

    Example:

    let name = "Rahul";

    function greet() {
    console.log(name);
    }

    greet(); // Rahul
    console.log(name); // Rahul

What is hoisting in JavaScript?

Hoisting in Js is behavior of processing declarations before executing the code. 

    greet(); // output hello

    function greet() {
    console.log("Hello");
    }

    Function declarations are fully hoisted, 
    ----------------------------------------------------------------------------
    example with var

    var name;

    console.log(name); // undefined

    var variables are hoisted with an initial value of undefined; 
    ----------------------------------------------------------------------------

    name = "Rahul";

    console.log(name); // This gives a ReferenceError

    let name = "Rahul";

    let and const are hoisted but remain in the 
    Temporal Dead Zone (TDZ) until their declaration is reached.

Destructuring in JavaScript

Destructuring is a JavaScript feature that allows us to extract values from 
arrays or properties from objects and assign them to variables in a concise way.

    example

    const user = {
    name: "Rahul",
    age: 25,
    city: "Mumbai"
    };

    const { name, age, city } = user;

    console.log(name); // Rahul
    console.log(age);  // 25
    console.log(city); // Mumbai

    Instead of:

    const name = user.name;
    const age = user.age;
    const city = user.city;

    Rename variables:

    const user = {
    name: "Rahul",
    age: 25
    };

    const { name: userName, age: userAge } = user;

    console.log(userName); // Rahul
    console.log(userAge);  // 25

Higher-order functions?

Functions that takes other functions as arguments

example:

const numbers = [1, 2, 3, 4];

const doubled = numbers.map(x => x * 2);

console.log(doubled); // [2, 4, 6, 8]

Here, map is a higher-order function because 
it accepts another function (x => x * 2) as an argument.
